# MAISON JADEX

**Where Culinary Art Meets Warm Hospitality** — An upscale fine-dining restaurant website built from scratch with HTML, CSS, and JavaScript.

## About the Project
Maison Jadex is an editorial restaurant experience featuring a seasonal tasting menu, visual dish gallery, opening hours, and a live table reservation system.

## Design & Aesthetic
* **Color Palette:** Deep Botanical Emerald and Warm Ivory surfaces accented with Champagne Gold borders and serif typography.
* **Typography:** Pairs *Cormorant Garamond* editorial headings with clean *Plus Jakarta Sans* copy.

## Features
* **Seasonal Tasting Menu:** Structured starters, signature mains, and artisan desserts with luxury pricing.
* **Visual Kitchen Gallery:** Responsive hover-zoom food photography grid.
* **Interactive Table Reservation Modal:** Formats the guest's chosen date, 12-hour AM/PM time, party size, and special requests into an instant confirmation card.

## Built With
* **HTML5** — Semantic restaurant layout
* **CSS3** — Custom variables, CSS Grid, Flexbox, and smooth hover transitions
* **Vanilla JavaScript** — Live date/time formatting and interactive reservation modal
